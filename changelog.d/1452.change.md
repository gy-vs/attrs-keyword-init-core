The merging rules for class-level and field-level *kw_only* have been fixed to match `dataclasses`: a class-level *kw_only* is now only the default for the class's own fields that don't set *kw_only* explicitly.
An explicit field-level `kw_only=True` *or* `kw_only=False` always takes precedence, and a subclass's class-level *kw_only* no longer modifies fields inherited from base classes.

The historic behavior (a class-level `kw_only=True` forcibly converting *all* fields, including inherited and explicitly opted-out ones) can be restored using the new `attr.set_force_kw_only_override()` switch, which only takes effect while enabled.
